## 3. 监控语义和限制

- Run 列表覆盖文档所有历史 revision；RunRow 本身无标准 revision 字段，因此不标记这些记录均属于当前源版本。
- `running` 表示数据库没有终态，不证明进程存活。无心跳、worker进程指标、GPU指标、实时token事件或远程取消接口；界面不伪造这些数据。
- 部分组件在结束时才持久化，事务中尚未提交的更新无法被轮询看到；最终监控精度取决于已有埋点。
- 父 pipeline / reader 的 metrics 可能包含子调用的累计值，列表不做跨记录总和。每条原始 metrics 在详情展示，便于核对预算、重试与缓存。
- Reader 检查点按 active_revision/is_active 过滤；指纹是否过期由正式 Reader/全文业务流程判定，查询不声称当前可恢复。
- 详情递归屏蔽已知凭据键和 Bearer/sk令牌，限制深度、数组/对象项数和长字符串；截断有标记。不读取 `.env`，不增加管理员热加载或数据库修改入口。脱敏不能保证去除所有文献或自由文本敏感内容，导出前仍需人工检查。
- 目前无 P7 登录鉴权；代理目标留在服务端环境文件，浏览器不录入密钥。适合本机/受信任开发网络，未进行正式发布。
- 请求失败/超时、切换文档或关闭浏览器不会取消后端执行；不自动重试 POST，先查 Run 再决定后续操作。
