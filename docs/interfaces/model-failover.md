# 文本模型主备与重试策略 · 2026-11-17

当前文本配置：`https://api.102465.xyz/v1`，主模型 `gpt-6-luna`，备用 `gpt-5.6-terra`。密钥仅保存于本地私有 `.env`；不写入本文件或验证报告。视觉模型独立配置，继续使用原端点和凭据。

## 调用路径

`config/models.yaml` 的 `llm` 池按主/备顺序配置。文本 default/chat 阶段显式启用 `fallback_on_retry_exhausted`；视觉阶段保持现有行为。CLI ask/resume、Skill、Reader等使用相同的任务路由策略。

- 每个模型的可重试请求最多3次（含首次），随后切到池中下一个模型；备用也最多3次，不无限循环。
- 可重试错误为超时、连接故障、429、5xx；401/403、普通400、Schema错误不自动切换，应检查凭据/请求/结构化输出。
- 纯文本provider `trust_env=false`，绕过当前进程继承的HTTP/SOCKS代理；直接调用与路由调用均遵循该配置。测试注入的HTTP客户端仍优先使用。
- 切换时保留原始请求及任务参数。返回的模型字段来自实际响应；路由的calls列表记录主/备候选调用。
- Skill与图像报告的模型配置指纹包含所有启用的候选，备用模型变化会使对应缓存失效；指纹不含密钥。
- 该策略仅为已授权的临时文本主备切换，不表示完整P7模型管理、熔断或用户鉴权已经实现。
