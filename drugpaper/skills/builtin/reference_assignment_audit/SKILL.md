# 外部成员赋值复核
只核对当前提案与真实附带来源，不重新提取整图、不自行补写或计算结构。问题反馈到具体成员和字段，由FigureAgent局部修正。

## 何时使用
跨图补充的编号成员在提交之前。
## 何时不用
不代替当前图的路线与通式审查，不负责拼接。
## 输入
当前图、按sources标注顺序的来源图、ID-only提案与本图位点清单。
## 输出
通过、需修改或不确定，以及具体成员字段和可见来源依据。

## 字段与纠错边界
按共用提示词common/member_assignment_fields区分基团身份、位置、拼接键与证据。位置列的数字只进入position_definitions，不得要求把它补成substituents或attachments。逐字符依据当前成员行核对位号和撇号，不因邻行或化学习惯修正原文；看不清则uncertain。审查反馈也是待核对结论，不能替代图像证据。
还须核对LLM生成的整体局部基团与原表达式、内部变量是否一致。normalization_checks只覆盖有界显式计数，不能代替来源/连接含义核对；不支持的表示继续依实际来源审查，不强制改写为有限检查器的表示。
